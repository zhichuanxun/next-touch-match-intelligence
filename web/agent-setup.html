Enable Agent

Agent is optional and off until configured. Match replay, tactical estimates, player metrics and timelines work without it.

Azure model

  1. Deploy a model supporting Azure OpenAI v1 Chat Completions in your own Azure resource.
  2. Copy the supplied environment example to .env. For a portable download, place it beside Start Next Touch; for source, place it in the repository root.
  3. Enter your actual resource endpoint, deployment name and private credential:
MATCH_AI_PROVIDER=azure
AZURE_OPENAI_ENDPOINT=https://YOUR-RESOURCE.openai.azure.com
AZURE_OPENAI_DEPLOYMENT=YOUR-DEPLOYMENT
AZURE_OPENAI_API_KEY=YOUR-PRIVATE-KEY
ENABLE_LIVE_AI=true
MATCH_AI_MAX_CALLS=16
MATCH_AI_MAX_TOKENS=900

Restart the app, then select Check configuration. Send a question to verify the connection. Configuration detection does not verify credentials or quota. Keep keys on the server; never enter or publish them in frontend code.

Other options

A running local Ollama model can be used with MATCH_AI_PROVIDER=ollama, without a cloud key. Model weights are not included. Set MATCH_AI_PROVIDER=disabled to switch Agent off.
